# Sales Performance Dashboard

## Overview
This Power BI dashboard provides insights into sales performance across categories, regions, and customer segments.

## Features
- Total Sales KPI
- Sales Trend Analysis
- Sales by Category
- Sales by Region
- Sales by Segment
- Interactive Filters

## Tools Used
- Power BI
- Excel
